# 🏠 Predicting House Prices using Linear Regression

![House Price Prediction](https://raw.githubusercontent.com/your-username/your-repo-name/main/assets/house_price_banner.png)

## 📌 Overview
The goal of this project is to develop a **Linear Regression model** that predicts the price of a house (in $1000s) based purely on **numerical property and neighborhood attributes**.

The dataset consists of residential properties described by quantitative features such as house size, number of rooms, age of the property, and proximity to important facilities. The model captures the relationship between these features and house prices to understand how each factor contributes to property valuation.

---

## 🎯 Objectives
- Accurately predict house prices using numerical features  
- Identify the most influential factors affecting house prices  
- Minimize prediction error using evaluation metrics:
  - **R² Score**
  - **Mean Absolute Error (MAE)**
  - **Root Mean Squared Error (RMSE)**

---

## 📊 Dataset Description
- The dataset contains only **numerical features**
- Target variable: **House Price (in $1000s)**
- Features include:
  - Property size
  - Number of rooms
  - Property age
  - Neighborhood-related numerical indicators

---

## 🛠️ Technologies Used
- Python 🐍

---

## 🔍 Model Used
- **Linear Regression**
- Feature scaling and data preprocessing
- Train-test split for evaluation

---

## 📈 Model Evaluation
The model performance is evaluated using:
- **R² Score** – Measures how well the model explains price variation  
- **MAE** – Average absolute prediction error  
- **RMSE** – Penalizes large errors and measures prediction accuracy  

---

## 📌 Results & Insights
- Identified key numerical factors that strongly influence house prices
- Achieved reliable prediction accuracy with minimal error
- Demonstrated how simple regression models can effectively solve real-world pricing problems
